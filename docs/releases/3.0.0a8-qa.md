## Delivered scope

The Python CLI adds `uc2 snapshot create`, `list`, `verify` and `restore`, also
available as `uc2-snapshot`. A repository is a directory containing independent
manifests and shared SHA-256-addressed UC2 chunks. All files are read and hashed;
reused chunks are decoded and verified. Restores verify complete file hashes
before publishing a new destination. Source trees must stay quiescent. Retention,
pruning, redundancy, ownership/ACL preservation and automatic repair are outside
this first version. See [the contract](../snapshots.md).

A reproducible two-version experiment added 42,782 bytes for the second snapshot
against 1,104,851 bytes for its separate tar ingest. Both versions restored,
corruption was detected, and replacement from an intact copy restored access.
This measures one controlled collection, not a universal speed or compression
claim. Timings and overhead are in [the benchmark](../benchmarks/2026-11-07-snapshots.md).

The C reader now decodes Turbo/method 80, including custom dictionaries. Generated
SuperMaster/NoMaster fixtures decode byte-for-byte with the original UC2 Pro 2.3
and an independent Go implementation. They are format fixtures, not output from
the original encoder. The writer does not emit Turbo. Optional interoperability
checks now cover 39 archives and 684 entries, including original-encoder oracle
archives. Original SAS 2.3 split/reassembly fixtures are pinned; direct multi-volume
reading remains open. See [corpus provenance](../../tests/archives/README.md).

The libarchive adapter now bounds variable decoder/metadata memory, input,
entry count, individual decoded entries and cumulative decoded output. The
opt-in shared LGPL reader includes Turbo. The prepared upstream patch has CMake
and Autotools dependency checks, quota tests, and a proposed format identifier.
No upstream contact, submission or acceptance has occurred. See
[the review package](../../contrib/libarchive/upstream/REVIEW.md).

## Validation

- 135 installed-package Python tests pass on Linux, including two-version
  restore, corruption/recovery, malformed manifests, portable paths, limits,
  source mutation, hardlink fallbacks and Windows timestamp semantics.
- All 27 native CTest tests pass, including original DOS round-trip. The 26
  non-DOS tests also pass under AddressSanitizer/UndefinedBehaviorSanitizer.
  The sanitizer run disables the integration test's address-space cap because
  ASan needs a large virtual mapping; the ordinary capped test passes separately.
- Turbo tests cover 18 size/master combinations, chained Turbo dictionaries,
  short/malformed/missing/cyclic dictionaries and same-handle retry after twelve
  injected allocation failure points. Only fully decoded dictionaries are cached.
- All 684 optional-corpus entry sizes and hashes agree with Go commit
  `53622f89ada1cf0d4a69f91b653bdd44ec5b0f92`; ZIP and tar migrations pass after
  the final decoder fixes. Third-party payloads are fetched separately.
- Real bsdtar quota and exact-boundary tests cover files and stdin, invalid
  options, overrides and a corrupt empty-file checksum. Enabled CMake and
  Autotools builds read Turbo; the disabled dependency build rejects UC2.
  The review patch applies to pinned libarchive 3.8.11. Its proposed ID was
  checked against current master; absence there does not assign it.
- Chromium tests verify Turbo downloads as well as legacy/rANS reads and the
  existing browser limits. Sphinx builds with warnings treated as errors.

## Scoped independent review

Codex authored these changes. Kimi replaces Claude at the user's request.
Gemini and Kimi reviews are recorded independently; Grok attempts that return
no verdict are misses, never approvals. The separate full-project task-qa and
task-at audit remains open (c9edf0b).

Rounds 1 and 2 led to Windows file-flush/hardlink fixes, source/repository overlap
rejection, exact manifest parent validation, stricter metadata checks, UTC date
validation, idempotent manifest publication, and decoding empty libarchive entries
so their checksums cannot be bypassed. Round 3 found no confirmed new substantive
issue, but local inspection then added Windows console-device and spaced-device
name rejection. Round 4 found the Turbo dictionary NULL-checksum crash and
incomplete master-cache state after errors; both were repaired with regressions.
Windows CI also exposed incompatible `fstat`/`lstat` ctime meanings. Snapshot code
now compares timestamps within each API and identities across them, retaining
before/after change detection. This matches the issue documented in
[CPython #157671](https://github.com/python/cpython/issues/157671).

Round 5 found no new decoder or snapshot defect. A portability suggestion
led to replacing C `tmpfile()` with libarchive's own anonymous temporary-file
helper, avoiding the Windows drive-root permission requirement. Linux builds
pass again; this does not claim native Windows validation of the optional
libarchive adapter. The other findings were checked against libarchive's state
machine and rejected: it skips unread data before the next header and disallows
data reads after archive EOF. A size-limit error on a corrupt existing chunk
is a correct refusal, though the wording could differ.

Round 6: Gemini and Kimi both returned no blocking or substantive findings.
Suggested diagnostic changes remain polish. Test assertions stay enabled in
Release builds through the repository's existing CMake test flags.

Round 7: Gemini returned no findings. Kimi's path-handling concern was tested
against both UC2 and ZIP: each reader exposes the stored `../evil` name, and
real bsdtar refuses extraction with its default secure-path flags. Neither
creates an escaped file. Format readers preserve metadata; filesystem writers
enforce extraction policy. The directory-size concern contradicts the native
reader's explicit zero assignment. Strict listing of corrupt snapshot manifests
is intentional; tolerant recovery enumeration is separate work. These are two
consecutive rounds with no confirmed new blocking or substantive issue.

Grok timed out without a verdict in all seven rounds, roughly 600 seconds each.
Those attempts are not approvals. Completed independent coverage is Gemini plus
Kimi, not a full three-reviewer panel. Raw prompts, outputs, exit statuses,
reproduction evidence and the triage ledger are retained locally under
`.git/qa-alpha8-20261107/`.

commit. Live HTML, CSS, JavaScript, WebAssembly and build-info hashes match the
CI browser artifact. An isolated Chromium session against the public URL verifies

binary is retained at `~/.local/share/uc2/uc2-before-alpha8`.

Snapshot retention/pruning and broader multi-volume work remain open, as do
libarchive upstream acceptance and the separate full-project audit.
