# UC2 3.0.0a5 release verification

This release repairs compression match lookup, adds the Linux read-only mount,
and packages the MC and WCX integrations. It also supplies a separate libarchive
review patch with an optional LGPL reader dependency.

- [Python package](https://pypi.org/project/uc2/3.0.0a5/)
- [Native CLI, integrations, source, and checksums](https://github.com/evvaletov/uc2/releases/tag/v3.0.0-alpha.5)
- [Compression measurements and underlying JSON/CSV](../benchmarks/2026-11-05-compression.md)

The release's `BUILD-INFO.json` identifies the source commit and CI runs.

## Compression

The old match finder inserted the current position before searching its hash
chain, immediately finding a zero-distance candidate and missing useful
matches. The repair searches before insertion, hashes all three bytes with
circular wrapping, and tracks absolute positions to reject stale generations.
New master blocks are limited to the format's 64,000-byte match distance.
Compression callbacks now reject premature EOF and oversized reads.

All eight Huffman/rANS levels have a repeated-random-data regression that
checks both decoded bytes and useful compression. A local ASan/UBSan
round-trip fuzz session completed 1,886 executions in 91 seconds without a
reported error. Its seeds span the circular-window boundary. CI also exercises
the decoder and round-trip fuzzers for bounded runs.

The benchmark compares alpha4 with this implementation on five synthetic
collections and two real source collections. Each collection has four methods
and three trials, giving 168 verified round trips across both implementations.
SHA-256 checks cover every restored file or tar payload. Ordinary UC2 source
archives are 62.6% and 69.4% smaller on the two real collections. The change
costs CPU, especially on random input; 7z still produces smaller archives in
every collection. These results do not establish a general advantage over
modern compressors. The benchmark report records sizes, timing caveats,
memory observations, provenance, and the remaining match-finder bottleneck.

## Local checks

The final Release build passed all 25 CTests, including original UC2 Pro
interoperability in both directions under DOSBox-X. That final DOSBox run took
816.72 seconds; an earlier run took 84.56 seconds. The emulator's variable
runtime is not a compression benchmark. Existing BLAKE3 unit tests are weak
and do not resolve the separately confirmed official-vector failures below.

All 43 Python tests passed. Eight new tests cover the mount's cache eviction,
random reads, stored versions, concurrency, limits, corrupt-file rejection,
and changed archive detection for both Huffman and rANS. The separate real
FUSE test mounted four files, read a stored version, verified 16 parallel
random reads with a one-entry/1 MiB cache, and confirmed writes were rejected.
It unmounted and closed the process afterward.

The MC installer preserves unrelated configuration, backs up edits, handles
existing UC2 rules, and is idempotent. Its installed helper was exercised with
the UC2 environment override removed. The prior integration work also tested
the unchanged helper protocol through the real MC interface.

## Native platforms and distributions

Twenty wheels cover CPython 3.10-3.14 on Linux x86-64, Windows x86-64, macOS
Intel, and macOS Apple Silicon. POSIX wheels run 43 tests; Windows runs 35
and skips eight POSIX mount tests. No macOS FUSE-mount support is claimed.
The source distribution is rebuilt into a wheel and tested too.

The four standalone CLI packages contain the matching wheel's executable.
The WCX package supplies both MSVC architectures with static C runtimes. The
ABI tests cover recognition, Unicode archive paths, listing, skip, test,
extraction, ambiguous-name rejection, and cancellation preserving existing
output. Native Total Commander 11.58.1 tests also open and extract a fixture
through the application's interface and compare the restored bytes.

The native application tests caught an incorrectly named capability export;
it is now `GetPackerCaps`, with an ABI regression check. The trial application
is fetched from its official location, hash- and Authenticode-checked, and
excluded from release packages. Matching source, licenses, build information,
and SHA-256 manifests accompany UC2's binaries.

## libarchive proposal

The [review patch](../../contrib/libarchive/upstream/REVIEW.md) applies to
unmodified libarchive 3.8.11. Enabled and disabled CMake configurations are
tested. The enabled native libarchive test passes 2,780 assertions, including
legacy data reads and explicit rANS rejection. Actual bsdtar tests cover
pipes, selected entries, directories, custom masters, and a 128 MiB entry
under a 96 MiB address-space limit. An Autotools build also restored the
legacy fixture byte for byte.

The optional shared `libuc2read` contains the existing LGPL decoder and
SuperMaster data; symbol and dependency inspection found no GPL compressor
or rANS module. The adapter uses the approved BSD option. This is a concrete
proposal, not an upstream submission or accepted format ID. Metadata and
dictionary memory growth still need a resource policy. The full local
libarchive integration and ordinary UC2 packages retain rANS support.

## Remaining limits

The project-wide task-qa + task-at audit remains open in git-bug `c9edf0b`.
This release has scoped engineering checks and prose edits, not a new completed
external review panel. The earlier alpha4 attempt completed one of three
requested external reviews.

The unused standalone BLAKE3 module still fails official vectors. Turbo/method
80, encryption, multi-volume archives, and offsets beyond the 32-bit format
remain unsupported. Python archive creation still uses the CLI. The FUSE
cache limits do not form a whole-process CPU or memory sandbox; see the
[mount guide](../mount.md) for limits and error behavior.
