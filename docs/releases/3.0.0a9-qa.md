# Alpha9 browser export and Total Commander routing

Alpha9 adds selected browser ZIP exports and offline use, and fixes native
32-bit Total Commander routing through ordinary `.uc2` plugin registration.
The browser changes are checked with independent Kimi/Gemini/Grok review
attempts; detailed outcomes and publication evidence will be recorded here
before release. This scope does not complete project-wide audit c9edf0b.

The browser exports up to 1,000 file versions and 128 MiB per ZIP, including
its inventory and headers. Every payload passes the UC2 checksum and receives
a SHA-256 digest. Portable numbered output paths map to original paths and
versions in `inventory.json`; empty directories are not exported. Any failed
file, cancellation or timeout prevents a partial ZIP download.

Offline saving caches only the digest-checked application, sample and notices.
User archives and decoded content are not cached. Updates wait for old tabs
to close. Browser storage may be evicted; the save action repairs missing
assets while connected. A native install prompt depends on the browser/OS;
OS-specific installation is not part of automated coverage.

Native Total Commander 11.58.1 tests use SHA-pinned, Authenticode-checked
executables on isolated Windows runners. Both architectures use `.uc2`,
normal WCX registration and no forced internal association. Exact extracted
file bytes and the loaded plugin are checked. Earlier users should remove
`*.uc2` / `**u2r` internal associations as described in the plugin README.
