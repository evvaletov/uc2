# Alpha10 snapshot maintenance, volume input and tar entries

Alpha10 adds explicit snapshot retention, verified replica repair and optional
SQLite packing; data-only SAS/DOS UC2SEA input; and `--ingest-tar` with named
entries and exact-file payload reuse. It also prepares an MC extfs contribution
and TC catalog request. Neither upstream proposal has been submitted.

Local validation covers the native C suite, installed-wheel Python tests,
USTAR/GNU/PAX/V7 parsing and atomic failure, original-encoder volume fixtures,
and malformed SEA path/checksum/length cases. A new sanitizer fuzz harness
exercises standalone Huffman streams. A 1,045-file public source tree restores
byte-for-byte after modification, rename and retention; the benchmark records
both logical storage and allocated filesystem space.

Independent scoped reviews use Kimi (replacing Claude), Gemini and opportunistic
Grok. Fixes include corrupted gzip repair, bounded inventories, lock cleanup,
retention timestamp validation, interrupted migration cleanup, complete restored
directory fsync, canonical SAS suffixes, V7 directories, absolute-directory
refusal, strict SEA output bounds across a ring wrap, two-byte final volumes,
basename-only sibling resolution and trailing compressed-word rejection.

The SEA corpus contains original UC2SEA compressed records. Its restricted DOS
extraction stub was removed and replaced by an inert synthetic envelope. Local
checks also verified original DOS-generated executables before stripping the
stub. The reader never runs executable or startup content.

Legacy classic-container decoder error semantics remain unchanged; strict
compressed-end validation applies to the new raw SEA path. Weak historical
checksums do not authenticate archives. General project audit c9edf0b remains
open; release-scoped panels do not close it. Snapshot packing retains fixed
reference/manifest limits. Tar payload reuse is whole-file sharing plus CDC
master dictionaries, with general per-file chunk references still tracked
separately. Writing new volume sets and platform SFX remains future work.
