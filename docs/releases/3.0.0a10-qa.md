# Alpha10 snapshot maintenance, volume input and tar entries

Alpha10 adds explicit snapshot retention, verified replica repair and optional
SQLite packing; data-only SAS/DOS UC2SEA input; and `--ingest-tar` with named
entries and exact-file payload reuse. It also prepares an MC extfs contribution
and TC catalog request. Neither upstream proposal has been submitted.

Local validation covers the native C suite, installed-wheel Python tests,
USTAR/GNU/PAX/V7 parsing and atomic failure, original-encoder volume fixtures,
and malformed SEA path/checksum/length cases. A new sanitizer fuzz harness
exercises standalone Huffman streams. A 1,045-file public source tree restores
byte-for-byte after modification, rename and retention; the benchmark records
both logical storage and allocated filesystem space.

Independent scoped reviews use Kimi (replacing Claude), Gemini and opportunistic
Grok. Fixes include corrupted gzip repair, bounded inventories, lock cleanup,
retention timestamp validation, interrupted migration cleanup, complete restored
directory fsync, canonical SAS suffixes, V7 directories, absolute-directory
refusal, strict SEA output bounds across a ring wrap, two-byte final volumes,
basename-only sibling resolution and trailing compressed-word rejection.

The SEA corpus contains original UC2SEA compressed records. Its restricted DOS
extraction stub was removed and replaced by an inert synthetic envelope. Local
checks also verified original DOS-generated executables before stripping the
stub. The reader never runs executable or startup content.

Legacy classic-container decoder error semantics remain unchanged; strict
compressed-end validation applies to the new raw SEA path. Weak historical
checksums do not authenticate archives. General project audit c9edf0b remains
open; release-scoped panels do not close it. Snapshot packing retains fixed
reference/manifest limits. Tar payload reuse is whole-file sharing plus CDC
master dictionaries, with general per-file chunk references still tracked
separately. Writing new volume sets and platform SFX remains future work.

See [snapshot details](../snapshots.md), [volume limits](../volumes.md),
[tar metadata mapping](../tar-ingestion.md), [MC proposal](../../contrib/mc/upstream/REVIEW.md)
and [TC draft](../../contrib/totalcommander/CATALOG-DRAFT.md).

## Published validation

Release source: `5c91f0e80cdf6ac8486367ed3fc0a6c8f01e1c5f`, tagged
[`v3.0.0-alpha.10`](https://github.com/evvaletov/uc2/releases/tag/v3.0.0-alpha.10).
[PyPI 3.0.0a10](https://pypi.org/project/uc2/3.0.0a10/) contains twenty wheels
and one source distribution. All 31 GitHub release assets were downloaded again
and matched the release SHA-256 inventory; PyPI hashes match the same artifacts.
The public wheel is installed locally, with existing command links retained.

- [Native CI](https://github.com/evvaletov/uc2/actions/runs/42378897889): Linux,
  macOS, MSVC, DJGPP, sanitizer fuzzing and integration builds pass. Local CTest
  passes all 28 cases, including the original DOS application round trip.
- [Distribution CI](https://github.com/evvaletov/uc2/actions/runs/42378897895):
  all twenty CPython 3.10–3.14 wheels are installed and tested across Linux
  x86-64, macOS Intel/Apple Silicon and Windows x86-64. The source distribution
  is rebuilt and tested. The local public-wheel suite passes all 178 tests;
  platform-specific tests skip where their prerequisites are unavailable.
- [Integration CI](https://github.com/evvaletov/uc2/actions/runs/42378897890):
  native 32-/64-bit Total Commander opens `.uc2` and verifies extracted bytes;
  WCX, MC and libarchive packages pass their packaging checks.
- [Browser CI](https://github.com/evvaletov/uc2/actions/runs/42378897891):
  Chromium, Firefox and WebKit pass. The first attempt failed one WebKit cache
  key assertion after an intentionally rejected update; the unchanged retry
  passed. The [main deployment](https://github.com/evvaletov/uc2/actions/runs/42379565450)
  also passed all three engines on its first attempt. The initial failure
  remains recorded for test-stability follow-up.
- The deployed reader matches all twenty expected public static files. Live
  Chromium and Firefox checks pass three offline ZIP exports per engine, with
  exact decoded contents, no archive cache entries and no uploads.
- The final standalone SEA sanitizer run completed 43,154 inputs in 91 seconds
  without a finding. CI also exercises the other two fuzz harnesses.

Final accepted Kimi/Gemini rounds are S5/S6 for snapshot maintenance, C3/C4 for
native volume/tar/writer changes and W4/W5 for the Python path bridge. There are
no confirmed outstanding substantive findings in those changed paths. Empty or
truncated replies were retried and never counted as clean; Grok's non-completing
rounds are misses. This is scoped review, with the project-wide audit still open.

Cross-platform fixes include transferring Windows handles into CPython's CRT,
handing descriptor ownership to Python through `open(opener=...)`, and preserving
POSIX byte paths with the filesystem converter. A regression holds twelve other
files open across repeated SEA reads. The invalid-UTF-8 filename test skips when
the filesystem itself rejects the name, as on the macOS CI filesystem.
