# Permission to publish the UC2 revival

Nico de Vries explicitly agreed to Eremey Valetov's request to publish his UC2
port as a public GitHub repository, with credit to de Vries and Jan Bobrowski.

## Source and dates

These excerpts come from a LinkedIn conversation supplied by Eremey Valetov
on 21 November 2026. The supplied view shows message dates and times, but no
year or time zone. The 8 March message is marked "Edited". Line wrapping has
been adjusted for this document; the quoted wording is unchanged.

## Publication request

Eremey Valetov, 8 March, 2:49 PM:

> Hi Nico,
>
> Thanks again for the source links! I got UC2 compiling and running on Oracle
> Linux 9 (native) and FreeDOS 1.4 (cross-compiled with DJGPP). Both work well.
>
> I've been cleaning up the build system and adding a macOS target as well.
> Would you be okay with me putting this up as a public GitHub repo? Full credit
> to you and Jan Bobrowski of course. I'd like to eventually expand platform
> support further -- OS/2 and others could be fun.
>
> Best,
> Eremey

## Permission

Nico de Vries, 10 March, 1:43 AM:

> Sure, go ahead.
