# Alpha13 review and publication record

UC2 3.0.0a13 adds automatic archive-layout selection and staged CLI extraction,
OTS attachment and proof extraction. The [release record](../releases/3.0.0a13-qa.md)
describes the behaviour and limits; the [benchmark record](../benchmarks/2026-11-20-auto-chunks.md)
contains the measurements.

Task-qa, task-at and task-elegance are complete. Grok 4.7 (returned as
`grok-4.7-build`), Fable 5.2 and GPT-6.2 Astra independently reviewed the changes.
Astra replaced Gemini Argon after authentication failed. An incomplete Terra
attempt is recorded separately and does not count towards closure.

Implementation rounds 7 and 8 had no confirmed substantive findings after
triage. The ledger retains the rejected Grok hypotheses and the source/native
MSVC evidence used to resolve them. A README correction from round 8 went
through separate prose review; all three reviewers passed the final prose
delta in pass 12. Reviewers inspected frozen source and evidence; they did not
independently execute the reported tests. See the [implementation ledger](alpha13-2026-11-20/reviews.json)
and [prose ledger](alpha13-2026-11-20/prose.json).

Validation passed 37 local CTest checks, 264 Python tests with two platform
skips, and 14 focused ASan/UBSan checks. Eight comparisons preserved exact
explicit-mode archive bytes. DOSBox-X verified automatic creation/extraction
and safe refusal to replace existing targets. The build, distribution,
integration and docs/browser CI runs all passed on release source
`b297757b7509b3b46be9002979eff5e3e20e6ea8`. Job links, checks and limitations are
in the [validation record](alpha13-2026-11-20/validation.json).

The [GitHub prerelease](https://github.com/evvaletov/uc2/releases/tag/v3.0.0-alpha.13)
and [PyPI version](https://pypi.org/project/uc2/3.0.0a13/) are published. All 31
GitHub assets were downloaded without authentication and matched the build
artifacts. All 21 PyPI distribution hashes matched. A fresh uncached PyPI
installation passed automatic-selection and native CLI transaction checks;
the downloaded standalone Linux CLI passed a separate smoke test.

SDF mirrors the source, [release tag](https://git.sdf.org/evv/uc2/src/tag/v3.0.0-alpha.13)
and git-bug records. All 75 tracker and identity refs matched both remotes.
GitHub hosts the binary assets. The tag and assets use `b297757`; subsequent
`main` commits contain documentation and evidence. The [publication receipt](alpha13-2026-11-20/publication.json)
records hashes, installation results and mirror checks.

Output publication is per file and does not guarantee power-loss durability.
DOS refuses existing destinations, including OTS attachment. Auto may select
shared chunks and require a 3.0.0a11 or newer reader; original DOS UC2 needs
classic mode at levels 2–5. Remaining Windows pathname and MinGW build issues
are tracked separately in git-bug `382f4cb`.
